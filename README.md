# Aspirai (Goal Getter Updated)
`AI-powered task creator and goal tracker`

- This project was created as the final project for my Headstarter Fellowship 2024. 

## Problem Definition
- **Lack of planning intelligence:** Conventional task apps Conventional task apps don’t support the thinking required to turn goals into actionable plans and tasks
- **No Goal Decomposition:** Insufficient support for breaking down complex goals leaves major plans waiting to be achieved
- **Cognitive Overload Trigger:** Undifferentiated lists generate cognitive overload and reduce execution quality
- **Structural Failure Pattern:** Without built-in guided structure and prioritization, motivation drops in a predictable pattern
- **The Gap:** Need for a system that reliably transforms broad ambitions into concrete, ordered, manageable steps


## Key Features
- **AI-Generated Tasks:** Get instant list of tasks tailored to help you achieve your goals more effectively
- **Customizable Plans:** Add your own custom tasks to create and personalize a plan that fits your unique needs and lifestyle
- **Progress Tracking:** Visualize your progress in each plan and stay on top of your goals to keep you motivated and focused
- **Task Management:** Mark tasks complete or remove them as necessary
- **User-friendly Interface:** Intuitive and easy to navigate
